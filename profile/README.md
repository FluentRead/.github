# FluentRead

### Make every webpage feel native to read.

An open-source browser extension for bilingual reading, instant selection translation, and flexible translation services.

[Official documentation](https://fluent.thinkstu.com/) · [Source code](https://github.com/Bistutu/FluentRead) · [Issues](https://github.com/Bistutu/FluentRead/issues)

</div>

FluentRead brings translation into the reading flow. Keep the original text beside the translation, translate only the text you need, or translate a whole webpage without opening another tab.

## What you can do

- **Bilingual pages** — Read original text and translations side by side.
- **Whole-page translation** — Translate and restore pages in place.
- **Selection translation** — Select text and get a focused translation card with copy and speech actions.
- **Flexible services** — Use Microsoft Translator, Google Translate, DeepL, DeepLX, Chrome Translator, or compatible AI providers.
- **Image translation (Beta)** — Run local OCR on text in images and display a reversible translated overlay.
- **Local-first settings** — Keep preferences and translation cache in your browser.
- **Cross-browser support** — Build for Chromium browsers and Firefox with WXT and Manifest V3.

## Free Translation

The built-in free fallback tries services in this order:

Microsoft Translator → DeepLX → Google Translate

## 中文简介

FluentRead 是一个开源的浏览器阅读与翻译扩展，致力于让每个网页都更自然、更流畅地阅读。

支持双语阅读、网页全文翻译、划词翻译、图片翻译，以及多种传统翻译服务和 AI 翻译接口。
